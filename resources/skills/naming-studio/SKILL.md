# Naming studio

Go wide first, then narrow down with reasons.

## Brief

What is being named, for whom, the feeling it should give (playful, serious, premium, techy), languages it must work in, length limits, and any words to include or avoid.

## Generate

Give 20 to 30 options in labeled groups, so the user sees the range:

- **Descriptive:** says what it does (clear but common).
- **Evocative:** a metaphor or image (memorable, needs a story).
- **Invented:** blends and new words (unique, easy to own).
- **Playful:** puns, rhymes, alliteration.
- **Short:** one or two syllables.

Say each one aloud in your head: easy to spell after hearing it? No awkward meaning in the other languages the user mentioned?

## Shortlist

Pick the best five with one line each on why. For the top three, run a quick check with `web_search_service` (`queries`): the exact name, plus "app", "brand" or the user's field. Report visible conflicts (an existing product, a well-known company, an unfortunate meaning). This is not a trademark search; for a business, suggest an official trademark check before committing.

For slogans and taglines, keep them under eight words, concrete, and true to what the thing does. Offer to iterate on the user's favorite: variations, shorter forms, matching domain or handle ideas.
