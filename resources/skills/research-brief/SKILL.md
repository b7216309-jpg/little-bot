# Research brief

Start from the decision or question already given. Use supplied materials and relevant workspace files; use current web sources when an available tool and network permission allow it. If access is missing, state the gap and work with the evidence available. Do not install a connector to satisfy this skill.

Keep a compact evidence record while reading: claim, source link or file path, relevant date, and uncertainty. Prefer original documents over summaries. Separate facts from your interpretation, and retain disagreements between sources instead of averaging them away. Never treat an inaccessible source as checked.

Choose the smallest useful result: a short brief for one question, a table for competing options, a longer document only when requested. Lead with the finding or recommendation, explain the decisive evidence, and flag assumptions that could change the conclusion. Cite material claims close to the text. Put open questions ahead of optional background.

When saving an artifact, include its preparation date and source references so it can be refreshed later. Read it back to catch unsupported conclusions and broken local references. Explain any material evidence gap in the handoff.
